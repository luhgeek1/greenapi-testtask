# MAX Client · GREEN-API

Браузерный клиент мессенджера MAX на базе GREEN-API: создание чатов по номеру телефона, отправка и получение текстовых сообщений, просмотр ответов API.

## Demo

[Открыть MAX Client](https://luhgeek1.github.io/greenapi-testtask/)

Для проверки без реального инстанса нажмите «Открыть демо» под полем `apiUrl`, затем «Подключиться». Демо использует вымышленные контакты и локальные ответы.

## Features

- Подключение к MAX-инстансу через `idInstance`, `apiTokenInstance` и `apiUrl`.
- Создание чата по номеру телефона с проверкой получателя через `checkAccount`.
- Список чатов, поиск, счётчики непрочитанных сообщений и отдельные черновики.
- Отправка текстовых сообщений через `sendMessage`.
- Автоматическое получение входящих через `receiveNotification` и подтверждение обработки через `deleteNotification`.
- API Terminal с ответами JSON, раскрытием логов и диагностикой `getSettings` / `getStateInstance`.
- Адаптивный интерфейс: на телефоне список чатов и переписка открываются отдельными экранами.

## Local run

Нужны Node.js 22.12+ и npm.

```bash
git clone https://github.com/luhgeek1/greenapi-testtask.git
cd greenapi-testtask
npm ci
npm run dev
```

Откройте адрес из терминала, обычно `http://127.0.0.1:5173`.

Для сборки и локального просмотра готового приложения:

```bash
npm run build
npm run preview
```

Откройте адрес из терминала, обычно `http://127.0.0.1:4173`.

Сборка сохраняется в `docs`. После push в `main` GitHub Actions проверяет проект и обновляет ветку `deploy`. GitHub Pages публикует папку `/docs` из этой ветки.

## GREEN-API setup

Создайте и авторизуйте инстанс MAX (`v3`) в [личном кабинете GREEN-API](https://console.green-api.com/). В окне подключения укажите значения из его настроек:

| Поле               | Значение                   |
| ------------------ | -------------------------- |
| `idInstance`       | Идентификатор MAX-инстанса |
| `apiTokenInstance` | API-токен инстанса         |
| `apiUrl`           | Адрес API-сервера инстанса |

Для получения сообщений через [HTTP API](https://green-api.com/v3/docs/api/receiving/technology-http-api/) задайте в личном кабинете:

- `webhookUrl` — пустая строка (`""`).
- `incomingWebhook` — `yes` («Получать уведомления о входящих сообщениях и файлах»).

Сохраните настройки и нажмите «Подключиться» в приложении.

## Tech stack

## Notes

- Токен хранится только в памяти текущей вкладки и не сохраняется в `localStorage` или `sessionStorage`.
- История чатов, сообщения и черновики очищаются после перезагрузки страницы.
